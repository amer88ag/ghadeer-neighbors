جيران حي الغدير بالمحالة — نسخة القرآن المدمج

README.txt

هذه النسخة تتضمن نص القرآن الكريم كاملًا بالمصحف العثماني داخل quran.json (114 سورة / 6236 آية) للقراءة والبحث دون اتصال بعد اكتمال تحميل ملفات الموقع.

مصدر النص: ملف qurantext-uthmani.def ضمن حزمة TeX Quran، مع الحفاظ على النص كما هو. لا يُنسب نص القرآن أو مصدره إلى مالك مشروع جيران الغدير.

الاستماع يستخدم رابطًا خارجيًا عند توفر الإنترنت، والتفسير يفتح مصدر tafsir.app.

قاعدة البيانات Supabase هي مصدر بيانات جيران الغدير المشترك. لا تحفظ الأرقام السرية في localStorage.
