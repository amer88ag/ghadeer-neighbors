# جيران حي الغدير بالمحالة — الإصدار 2.0 (إعادة بناء)

تطبيق ويب ثابت (بدون إطار عمل) لمجموعة جيران حي الغدير: القهوة، الطلعات، مناسبات الحي، دليل الجيران، الرسائل العامة والخاصة، تفقد الجار، خدمات الحي، سكن الحي، ولوحة الإدارة.

## الهيكل

```
index.html                 الصفحة الوحيدة (تحمّل مكتبة Supabase و src/app.js فقط)
src/
  config.js                ثوابت المشروع (Supabase، الموقع، الإصدار)
  app.js                   نقطة الدخول: تسجيل الصفحات والإطار العام
  styles.css               ملف التنسيق الوحيد (فاتح/داكن)
  lib/
    api.js                 الطبقة الوحيدة التي تتصل بقاعدة البيانات
    session.js             الدخول، المدير، تذكّر الجهاز، الشروط، استعادة الرقم
    router.js              موجّه واحد (#/page/param)
    data.js                بيانات مشتركة مع ذاكرة مؤقتة
    dom.js                 أدوات الواجهة (نوافذ، إشعارات، تنسيق)
    widgets.js             الصلاة، الطقس، الذكر، الأحاديث
    catalog.js / links.js  دليل الخدمات والروابط الخارجية
  pages/                   صفحة واحدة لكل قسم، كل صفحة تصدّر render(el, params)
supabase/migrations/       ترحيلات قاعدة البيانات
scripts/check.js           فحص الصياغة والقيود المعمارية والأمنية
tests/                     اختبار متصفح كامل على قاعدة بيانات وهمية
build.js                   يفحص ثم يبني dist/
```

## القواعد المعمارية (يفرضها `scripts/check.js`)

- لا اتصال بقاعدة البيانات إلا من `src/lib/api.js`.
- لا تخزين للرقم السري في المتصفح إطلاقًا (يبقى في الذاكرة فقط).
- لا `alert/prompt/confirm`؛ النوافذ من `dom.js`.
- لا أي ارتباط بمشاريع أخرى (قرآن، مدرستي، جداول communities/account_*).
- كل صفحة في `src/pages` تصدّر `render`.

## التشغيل محليًا

```
node build.js
cd dist && python3 -m http.server 8765
```

## النشر

- **Vercel**: `vercel.json` يبني `dist/`. نشر Production موقوف عمدًا عبر `ignoreCommand` (المعاينات Preview تعمل). لإعادة تفعيل الإنتاج احذف سطر `ignoreCommand`.

تفاصيل التدقيق وما تغيّر: `docs/AUDIT.md`. خطوات قاعدة البيانات: `docs/DATABASE.md`.
