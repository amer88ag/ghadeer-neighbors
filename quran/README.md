# Quran Module — وردي

مسار مستقل وقابل للتطوير والتعديل داخل المشروع.

## Contract

- Route: `/quran`
- serviceKey: `svc_quran`
- Module owner: `quran/`
- لا تعتمد الوحدة على `window.render` أو سجل History المركزي مباشرة.
- أي انتقال يتم عبر بوابة التنقل المركزية.
- مصدر النص القرآني منفصل عن طبقة العرض.
- الصوت، التفسير، التجويد، الحفظ، والبحث طبقات مستقلة قابلة للاستبدال.
- لا تعتبر أي وظيفة `verified` قبل الاختبار الفعلي.

## Planned layers

1. `reader` — المصحف والرسم العثماني والتصفح والتكبير.
2. `audio` — التلاوة والتكرار والمزامنة.
3. `tafsir` — التفسير ومصادره.
4. `tajweed` — التجويد والتعليم.
5. `hifz` — الحفظ والمراجعة والاختبار.
6. `recitation` — تسجيل قراءة المستخدم وتحليلها كمساعد تعليمي.
7. `search` — البحث في السور والآيات.
8. `offline` — تنزيل المحتوى المسموح به وتخزينه محليًا.
9. `settings` — إعدادات القراءة والصوت وإمكانية الوصول.

## Source policy

لا يوضع نص قرآني أو تفسير أو صوت في الوحدة من مصدر مجهول. لكل نوع محتوى يجب توثيق المصدر والترخيص قبل إدخاله في Release Candidate.

## Legacy

`ghadeer-quran-v5.js` لا يمثل واجهة Quran V2 الجديدة. يمكن الرجوع إليه فقط لاستخراج وظائف مفيدة أثناء إعادة البناء، ولا يُعاد تقديمه كواجهة نهائية.
